# 开篇:我们要怎么读懂 Suricata 源码

网上关于 Suricata 的文章大多停在"怎么用"——装引擎、写规则、调参数。但如果你想知道一个包从网卡进来到告警落盘,中间到底经过了哪些代码,这类文章基本帮不上忙,最后还是得自己一头扎进几十万行 C 代码里摸索。

这个系列就是我自己摸索的记录:不讲规则语法、不讲部署调优,只带你看引擎内部——它是怎么组织的、每个子系统的核心数据结构是什么、关键路径在哪个文件的哪一行。目标是读完之后你能在源码里"认路",而不是记住一堆知识点。

写给谁看:有 C 基础、对网络协议栈不陌生、想搞懂一个成熟开源安全引擎是怎么写出来的人。每篇都会给出具体的 `文件:行号`,方便对照源码食用。

## 系列篇目

1. **整体架构与启动流程** —— 从 `main()` 到第一个包被处理之前,进程里到底发生了什么,先画一张全局地图。[已发布]
2. **线程模型与 TmModule 机制** —— Suricata 的"流水线"是怎么拼出来的:`TmModule`、`ThreadVars`,以及 single / autofp / workers 三种跑法的代码差异。
3. **数据包的诞生:捕获与 Packet 结构体** —— AF_PACKET / PCAP / NFQ 这些抓包后端如何把一个包塞进引擎,`Packet` 结构体和它背后的内存池设计。
4. **解码层:从比特流到协议字段** —— 以太网、IP、TCP 一层层剥开的过程,顺带看看 Suricata 怎么处理畸形包和隧道协议。
5. **Flow 引擎:让引擎有"记忆"** —— 流表怎么建、怎么查、怎么超时回收,为什么说 Flow 是整个引擎的核心枢纽。
6. **Stream 引擎:TCP 重组不为人知的复杂度** —— 乱序、重传、gap、注入攻击(evasion),状态机是怎么兜住这些脏活的。
7. **应用层解析框架** —— 协议探测(probing parser)和解析器注册机制,以 HTTP 为例走一遍完整链路。
8. **检测引擎总览:规则是怎么变成代码的** —— 从一行规则文本到可执行的匹配结构,`Signature`/`SigMatch` 长什么样。
9. **多模式匹配与规则分组** —— 几万条规则同时生效,引擎为什么还能跑到线速,MPM 和签名分组(SGH)是关键。
10. **输出与告警:从命中规则到一行 JSON** —— `output` 模块注册机制,EVE JSON 日志是怎么攒出来的。

顺序可能会根据写作过程中的取舍微调,但大方向不变:先搭骨架,再填血肉。
